# Attendance Calculator

A clean and responsive attendance calculator built for students to track attendance percentage, calculate safe bunks, and find how many consecutive classes are needed to reach a target attendance.

## 🚀 Features

- Real-time attendance calculation
- Safe bunk prediction
- Recovery streak calculation
- Adjustable attendance target
- Light & Dark mode
- Responsive minimal UI

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
- **Tailwind CSS**

## 💻 How to Use

1. Open `index.html` in your browser.
2. Enter:
   - Total classes conducted
   - Classes attended
3. Adjust your target attendance using the slider.
4. The calculator will instantly show:
   - Current attendance percentage
   - Safe bunk count
   - Required recovery classes
